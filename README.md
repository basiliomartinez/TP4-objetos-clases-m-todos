# TP4 – Objetos, Clases y Métodos  
Proyecto educativo para practicar **Programación Orientada a Objetos (POO)** en **JavaScript**, siguiendo el estilo de uso de **propiedades privadas (`#`)**, **getters/setters**, **métodos**, `document.writeln`, herencia y polimorfismo. Incluye ejercicios paso a paso como Auto, Cuenta Bancaria, Rectángulo, Producto, Persona y Agenda Telefónica con menú mediante `prompt`. 

🔧 Herramientas: **JavaScript (ES2022+)**, **HTML**, **VS Code** 

 ▶️ Para usar el repositorio: clonar con `git clone https://github.com/basiliomartinez/TP4-objetos-clases-m-todos.git`, abrir en VS Code, lanzar `index.html` con Live Server y probar cada script de los ejercicios (cada uno imprime resultados en pantalla y consola).
